## 10
### Histórico do navegador.
**pilha**: pois a lógica dessa estrutura se encaixa com a proposta de histórico,na qual a ultima informação tem ser a primeira a ser mostrada,ou acessada.
### Pessoas aguardando atendimento.
**fila**: pois está estrutura de dados tem a lógica que satisfaz o problema de gerenciar o atendimento,pois o primeiro dado a ser armazenado é o primeiro a ser acessado.
### Catálogo de produtos.
 **lista**: a estrutura de fila é a melhor para esse caso,pois não tem uma ordem especifica de acesso,o usuário pode selecionar tanto o ultimo
 produto como o primeiro.
### Função “desfazer” de um editor de texto.
**pilha**: Por a função desfazer retornar ao estado anterior a pilha é a estrutura qua mais se encaixa para essa função,sempre o estado anterior sendo o segundo 'item' da pilha
### Playlist de músicas que pode ser acessada por posição.
**lista**: a lista é a estrutura que melhor funciona pois o usuário pode querer selecionar uma música mais a frente da lista ou mais a trás,sendo assim a lista proporciona a liberdade que essa logica de **playlist** precisa
